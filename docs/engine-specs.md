# Private raw engine/spec loading profile

This bounded profile covers original engine construction and reset, scoped vehicle-ID mappings, and road Action0 properties08/09/0F/11. It does not admit configured-NewGRF saved-world restoration, execute arbitrary baseline content, finalize cargo/refits or restore saved dynamic engines. All broad Stage4 gates remain open.

The ten fixed witnesses are empty loader/reset, dynamic engines on/off direct API, scalar loader, later truncated loader, and later unknown-property loader, unknown-property continuation stop, recognized-prefix continuation, and high-local-ID retained reset with dynamic engines on/off. API snapshots compare every command's full raw owner/mapping/temporary state and reader outcome. Loader snapshots compare reset or pre-finalization state plus configured-file status/errors. Full native event streams are retained; this is not a claim that every native event has a matching Rust event. Native RNG is bound within each actual invocation; no cross-process interactive-RNG equality or Rust/native context parity is claimed.

The API test uses the same production road-property implementation as the private loader, not a second Rust translation. Temporary state, allocation before failed reads, retained mappings and512-owner host refusal remain explicit. Public configured-world refusal is unchanged.

`scripts/capture-engine-specs.py --output ABSOLUTE_FRESH_PATH` builds a fresh Cargo `--locked` test executable and compares ten original witnesses, runs12 native host guards, nine wrapper invocations in five groups, eight exact focused tests, thirteen real admission-corruption probes, a zero-test refusal and complete archive verification. `CARGO_TARGET_DIR` must be fresh and outside source/output; the default is a unique system-temp path. Its actual selected executable and a retained byte-identical copy remain bound in evidence. Native execution requires a fresh matching build from tracked setup/reference inputs; historical local evidence binaries are not a CI recipe.

The capture writes `verified_native_corpus=false` outside the frozen source and prints CAPTURE. The tracked expanded layout contains the reviewed native observations for this bounded profile. `scripts/check-engine-specs-ci.py` is the normal driver for contract scenario `content.raw-engine-specs`; each run builds a fresh locked Cargo executable and repeats the complete corpus and admission checks. A capture cannot replace that normal run. The driver refuses an unverified layout.

Required artifacts include all invocation/process logs, compiled corpus/source/binary bindings, unmodified native/control/spec snapshots, Rust outputs, baseline byte hashes, negative-probe mutations and diagnostics, source copies and a verified archive. Native semantic errors (ReadBounds/UnknownProperty) disable configured files; host input/storage refusals remain distinct. Corruption probes run the actual validator on a passing unmodified baseline before and after each reversible mutation, including a paired owner mutation that equality alone would miss.

High road local IDs preserve their u16 identity. Only substitute selection uses native uint8 narrowing before the original-table-count minimum. Raw non-original road construction uses Price{} (StationValue); public finalized defaults remain unchanged. IDs88,255,256,257,343,344,512,65535, property08 and retained reset are compared as complete owners/mappings/temporary state in both dynamic modes. Existing second-GRF original-local0 witnesses remain separate because they copy original table data. Non-original rail construction is unadmitted pending its own native whole-owner extension.
