# Pinned Squirrel table hooks and default-method execution

This is a source-first proposal on `e66410f2889c5534ae9da591367c03d50378d7e4`, not an implementation or approval. The oracle is OpenTTD 15.3, Git `14ec60f248547d4d062a1160f0fc26d742319888`. All native paths below are under `src/3rdparty/squirrel/`; line numbers refer to that pin. Exact source copies, bodies, invocations, raw channels, executable identities and expected-parity failures are in `.omo/evidence/script-hooks-design/`. The former delegation checkout and its sealed proof remain unchanged.

## Decision and scope

Implement real nested invocation, weak references and shared default registrations before removing the current reached-hook refusals. Then implement every defined table hook consumer and all 48 registrations for current value families: table 8, array 15, string 9, number 5, closure 8 and weakref 3. This is a dependency sequence, not six independent shortcuts. Classes, instances, generators, threads, other libraries, host scheduling, AI/GS integration and persistence remain required later work; their 18 additional default registrations are inventoried, not implemented by this proposal. Existing undefined-input policy, ordinary delegates, parent access, compiler diagnostics, trap semantics and public typed failures remain binding.

Three approaches were considered. A second Runner/VM for hooks loses physical stack, shared operation debt, temporary/error roots and frame ownership. Calling the existing ordinary `script_call` and borrowing its outer traps makes ignored hook errors catch in the wrong invocation. The recommended approach adds a private nested execution boundary inside the same VM, with local trap accounting, an invocation-root marker and shared physical state. This requires prerequisite work but directly corresponds to `CallMetaMethod` → `Call` → `Execute`.

No generic `Display` conversion or method-name wrapper is acceptable. Defaults are actual unbound NativeClosure objects. An absent hook, a noncallable hook, a successful null result and a failed invocation are distinct. A retained historical `_lasterror` does not mean the current operation failed.

## Source dispatch and instruction ordering

`squirrel/sqobject.cpp:117–121` obtains a metamethod from the immediate delegate's own table slot, resolving a stored weak reference through `SQTable::Get`. It does not recursively find an inherited hook. Ordinary Get/Set independently walk delegates before attempting the current receiver's hook, so those paths can execute several different hooks during one lookup.

`squirrel/sqvm.cpp:1511–1523` retains the selected hook in a local `SQObjectPtr`, calls with `raiseerror=false, can_suspend=false`, then pops all pushed parameters on both outcomes. Script and native closures are callable here. A table-valued hook is not recursively dispatched through its `_call`; `Call` at 1478–1510 returns false for that type. The general class branch exists in the source and remains a prerequisite when classes are admitted.

`sqvm.cpp:1230–1324` performs own-slot access, fallback, then current-`this` root/constant fallback when requested. Array numeric indexing returns directly. Table fallback recursively Gets the delegate, refuses further hooks for raw lookup, attempts immediate `_get`, then checks the shared table default. Thus `t.len` can find the ancestor's default `len` before the child's `_get` executes. The retained body named `get-throw-default-fallback` actually demonstrates this precedence and leaves last_error null; its rule was corrected without altering its source or receipts. The separate `supplement/root-fallback.nut` genuinely throws from `_get`, then succeeds from the configured root, retaining `"hook-get"`.

`sqvm.cpp:1327–1369` performs own Set, recursive parent Set without root fallback, immediate `_set`, then current-`this` configured-root Set. Default methods do not participate in Set. Null keys and unsupported native conversions still fail at their original earlier boundaries. Opcode Get/Set/PREPCALL and Symbol capture raise the common index diagnostic after a false result; successful fallback can retain a failed hook's arbitrary error object.

Equality does not call `_cmp`. Right-hand arithmetic fallback is not invented. Table/array foreach use physical Next; `_nexti` is for userdata/instances, and `_newmember`/`_inherited` are class work. `in`, raw VM lookup, native `rawget`, user delegate traversal and default lookup remain separate operations.

## Nested Execute, native calls and budget

The existing public `Vm::resume` cannot serve as the inner evaluator: it adds credit, permits suspension and performs terminal cleanup. Add private invocation state with entry frame depth, entry trap length/local active trap count, root-frame identity, saved suspension permission and native-call nesting count. Physical registers, `_top`, `_stackbase`, varargs, global temporary, Runner error object and operation counter are shared, not copied into a child VM.

`sqvm.cpp:690–750` increments `_nnativecalls`, creates a fresh local `traps=0`, assigns the global temporary on ET_CALL, calls StartCall and marks the entry CallInfo as root. Each instruction decrements the shared counter before suspension/error checks and fetch. Inner `can_suspend=false` consumes negative operation debt until completion; only the resumed outer loop may suspend. Actual `nested-hook-budget` schedule 1 shows outer suspension debts `-42` and `-27`, without an inner suspension. Do not add native body costs or reset debt. The default excessive-CPU threshold is INT64_MIN; source-defined threshold/stack limits require typed safe checks, not overflow probes. The pinned native nesting guard is 100.

`sqvm.cpp:341–450` orders arity/default/physical-varargs movement, weak environment receiver substitution, CallInfo installation and register growth. Return restores base/top, pops varargs and CallInfo, publishes the root/target result, then clears exactly the native range. `CallInfo` deltas/target/traps/call count are signed 32-bit; vararg size/base unsigned 16-bit; offsets/counters use 64-bit SQInteger. Checked Rust conversions retain malformed/undefined refusals rather than truncating. Valid tail calls must preserve the nested root flag; the existing undefined vararg-tail guard remains unchanged.

`sqvm.cpp:1055–1113` retains `currerror` during unwind. Only traps installed in the current Execute may catch the inner failure; a caller's trap is reached only after the enclosing operation decides to fail. Restore target, trap pop, inclusive stack clearing, physical varargs and frame destruction in source order. An ignored `_cloned` throw must not trigger an outer catch. A Get failure may instead become the index string caught by the caller. Inner catches must not consume outer traps. Policy, undefined-input and invalid-bytecode errors remain uncatchable and cannot be converted into a normal failed-hook fallback.

`sqvm.cpp:1140–1228` checks native arity before receiver/argument type masks; positive check is exact, negative check a minimum. Masks apply only to existing arguments covered by the mask list. Native CallInfo retains its closure. Captures are pushed, then the weak environment may replace the receiver after type checks. The native body runs with suspension disabled. Restore base/top and preserve the literal native cleanup bound involving oldtop, oldstackbase and the already absolute argument stackbase; do not “correct” it to a conventional slice. For a negative return, restore base/top, pop CallInfo, clear the source range and retain/raise last_error. For success, a positive return takes TOP and clears it (zero returns null) before restoring base/top, popping CallInfo and clearing the source range. `sqapi.cpp:970–993` adds the sq_call adapter used by call/acall/sort: no new credit for default `suspend=-1`, Pop(params) on completion/failure; on success the source-defined excessive-CPU check precedes any optional result push. Its `_can_suspend` assignment is not an independently restoring abstraction.

The implementation must distinguish an inner raised outcome from the retained error state and restore the outer instruction's raised marker deliberately. `native_error()` and its existing const/public signatures remain compatible; `native_error_value()` remains the authoritative borrowed arbitrary Value. Never create a duplicate permanent error owner to report a typed failure.

## Ownership and collection prerequisites

C++ reference ownership and GC root membership are different. A local `SQObjectPtr` retains reference count but is not enumerated as a collector root. Current Rust public Handle/Value owners increment `Life.external`, and collection seeds every external entry. Using those public Values for all newly introduced hook temporaries would incorrectly root them during nested collection. This is a concrete prerequisite, not permission for an unrelated collector rewrite.

Add an internal retained operand representation backed by an internal Edge/Stored value and a VM-held Realm lifetime. It owns the native reference but does not register a collector root. Its access is generation-checked and its drop drains pending retirement only after mutable heap borrows have ended. Keep public Value owners and their current host contract. Explicit VM/shared-state root enumeration supplies actual roots; do not hide local owners in that enumeration. A finalized-but-still-reference-owned object must remain safely represented until its last reference releases, with source-specific cleared contents; collection cannot leave a dangling Rust operand. This representation and an active-root oracle must be proven before enabling hook execution with collection.

`sqobject.cpp:487–498` marks VM last_error, errorhandler, debughook, root table, global temporary, the entire allocated stack (not only live top), physical varargs and all CallInfo closures. `sqstate.cpp:267–329` seeds root VM, native RefTable, registry/constants/metamethod map and all ten default tables, then uses a LIFO marker queue and rebuilds the live chain. Existing e664 delegate-first enqueue, ordinary delegate-before-nodes release, nodes-before-delegate GC clearing and immediate per-node release remain intact. A full native pointer-hashed host RefTable remains outside current public-host parity; do not describe external-entry enumeration as that implementation.

`CallMetaMethod` retains the chosen closure until after parameter Pop. `Execute` overwrites the global temporary with the invoked closure and does not automatically restore its former value. Result destinations also differ: Get and unary/arithmetic paths can use global temporary; TypeOf writes target; Clone has a shadowing local temporary; compound update uses a local value; Symbol capture uses its local capture value. An adapter must select the actual destination/owner lifetime, not eagerly clone every return into global temporary or an extra Rust root. Failure unwind's local `currerror` is a reference owner for its source lifetime only.

Passive owner proposal for implementation approval: reuse the e664 bounded free-event recorder at observer `sq_vm_free` only. Setup scripts expose live O/D/hook/result through a genuinely rooted array; register borrowed scalar pointer labels before releasing that setup owner. Observe before/after refcounts, full marked chain and retirement order; never Get/AddRef solely for observation, dereference freed pointers or coerce arbitrary last_error through sq_getstring. Exercise hook detaching its delegate, ignored thrown aggregate, failed Get replaced by string, returned graph, weak-bound environment, nested varargs and a hook reachable only through the active frame.

For active nested collection, add a separately approved dedicated observer host print callback that explicitly invokes sq_collectgarbage at a fixed finite script marker; the Rust PrintSink invokes Realm collection at the same point. This is an intentional host collection action, not a passive recorder or timing hook. Record no-op/on callback controls and endpoints, reference counts/roots before collection, actual retirements and state afterward. No extra graph owners or native-core changes. The shared passive recorder remains unchanged. Active collection has not been executed in this design; existing language probes alone do not prove its root ordering. If source-safe active observation cannot be established, this prerequisite remains open rather than claiming full hook/GC parity.

## Weak reference semantics

`sqobject.h:55–88`, `sqobject.cpp:91–114`, `sqapi.cpp:1202–1219`: each refcounted object caches one weak-wrapper identity. The wrapper is reference-counted but not SQCollectable and does not AddRef its target. Target destruction nulls the wrapper; wrapper destruction clears a still-live target's cache. Scalar weakref returns the scalar itself. Strings and weak wrappers themselves are refcounted targets too. `bindenv` at `sqapi.cpp:410–435` clones the closure identity and stores a weak environment, not a strong table edge; expiration substitutes null.

Add a distinct WeakRef value and stored representation outside the collectable object graph. It can weakly address graph Life/generation, interned StringData and WeakRefData. The referent cache must not strongly own the wrapper or target. Finalization alone is not target destruction: a weak reference clears at actual target retirement. A reused allocation/slot cannot revive an expired generation. Existing native-error APIs must dispatch the new type without invalid casts; production observer support requires source approval and new exact build custody.

Stored weak references and real reads are not interchangeable. `sqtable.cpp:88–98,156–169` Get/normal Next dereference `_realval`, while clone's Next(true) preserves the wrapper. `sqarray.h:24–51` Get/Next resolve it; Clone copies it; Top/Pop preserve stored wrappers; remove and slice materialize through Get. Registers, capture/default copies and LOADFREEVAR copy values as stored. Introduce explicit `stored_value` versus `read_real_value` operations and audit each source call site; do not globally change `Stored::value`.

## Default registrations and bodies

`sqstate.cpp:74–85,143–152` creates one real NativeClosure per registration and one default table per family for a SharedState. Registrations sharing a C++ function pointer remain different closure identities (`append`/`push`, table.len/array.len). Repeated lookup returns the same registration object; extraction is unbound and PREPCALL supplies this. Defaults do not become user parent nodes or raw own slots. Friend VMs share the registry. All ten default tables are explicit shared-state GC roots, with source-defined initialization and teardown order.

Separate NativeFunction body identity from registration name, arity, masks and closure object identity. Put registry storage in shared Realm state without a Realm→Handle→Realm strong cycle: internal root edges plus explicit shared-root enumeration, initialized once before user object allocation through a private fallible allocation boundary. Preserve public Realm::new compatibility; do not create lazy fresh closures per lookup. `sqstate.cpp:35–72` supplies mask grammar and `sqdebug.cpp:109–127` supplies exact union ordering and parameter diagnostics; the current special array check is insufficient.

The machine-readable `default-registry.json` records every original registration's source line, name, function, arity and mask. Required current families are:

`table.rawset` null-key refusal is `null key`; `clear`'s dot mask allows an extracted table method called with an array, but its body rejects other types. Native type checks precede bindenv receiver substitution. `getinfos` returns source-visible name/paramscheck/typecheck for native closures and name/source/parameters/varargs metadata for script closures; this must use actual existing Prototype data.

Array sort invokes sq_call(root,a,b). A failed comparator preserves a string error but replaces a non-string throw with `compare func failed`; intermediate swaps and array-size checks remain observable. The corpus uses finite safe arrays; it does not exercise resize-induced invalid native accesses. Optional slice argument handling reads physical stack slot 2 even if absent, so its source stack initialization/TOP lifetime must be proven before a missing-argument case is admitted; do not manufacture null or infer behavior from a convenience API.

String conversion's dotted branch uses C-string strtod; non-dotted integer parsing uses full-length `ParseInteger<int64_t>` (`src/core/string_consumer.hpp:917–929`) with source whitespace rules. These differ for embedded NUL/trailing input. Ctype calls receive char in this pin: negative-char Unicode case-fold probes are not executed. Existing valid Unicode strings/comments and byte slice/find remain native. No new undefined-policy classification is declared by this design.

## Address formatting and identity

Native ToString fallback is `fmt::format("({} : 0x{:08X})", GetTypeName(o), (size_t)(void*)_rawval(o))`: uppercase hexadecimal with minimum width eight, type name and actual own-process object address. Arrays/closures use their object address; weakrefs use wrapper address. A formatted string owns bytes, not the object. Failed/non-string `_tostring` still takes this path, retaining prior error. Ordinary float ToString uses fmt default formatting; diagnostic PrintObjVal uses `.14g`. Preserve that distinction and the existing byte-string behavior.

Five repeats of each of two identical native bodies produced five distinct raw address-bearing outputs. This is ordinary cross-process value variation, not undefined source. Eight raw address-bearing bodies are retained, unnormalized and uncredited for cross-process equality. Existing strict drivers are unchanged. A future address observable needs a separately explicit semantic check of each own-process value; it cannot waive the whole body or replace pointers with a constant string.

Use an actual stable nonzero allocation identity in Rust, with a safely obtained address of nonzero-sized aligned storage whose lifetime matches native object retirement. Do not format a moving Vec slot, temporary Handle, generation counter or fake fixture string. The same identity source must serve formatting and table `_cmp` pointer fallback. Source aggregate-key hashing (`sqtable.h:13`, pointer shifted by three) must use that same source if/when aggregate keys are admitted; existing unsupported-hash policy remains until that separately tested capability exists. Native pointer ordering/allocator address values are not portably reproduced numerically across processes.

Required checks: exact format/min-width/uppercase/type; same alias stability; distinct simultaneously live objects; string lifetime independent of target; weak invalidation through actual retirement; no resurrection after slot/address reuse; ordering agrees with formatted numeric identity after failed `_cmp`; no hook invocation for same-object comparison; no normalization of bytes returned by user-defined tostring. Current `address-format-alias`, `weak-address-string-outlives-target`, `cmp-throw-address-fallback` establish deterministic original endpoints. The supplementary wrong-prefix and wrong-alias native assertions fail, and baseline/restored bodies pass. Actual numeric address reuse has not been forced or observed; implementation must add a safe lifecycle test without allocator assumptions and retain any original reuse observations separately.

## Primitive interfaces and implementation atoms

The following are private boundaries, not committed Rust APIs. All touched/new Rust or Python files must remain at most 250 pure lines, with cohesive responsibilities and unchanged strict settings.

1. **Invocation/owner prerequisite.** Own `vm.rs`, `vm/frames.rs`, `vm/traps.rs`, `vm/calls.rs` and focused new `vm/invocation.rs`, `vm/native_frame.rs`, `vm/operand_owner.rs`; narrowly update heap ownership/root enumeration only for the proven nested case. Introduce `InvocationBoundary { frame_depth, trap_floor, local_traps, root, can_suspend, native_depth }`. Extract existing ordinary paths without changing selectors or source-ordered owners. Prove full old owner/trap traces plus dedicated active-collection RED before semantic change; archive moved-body equivalence separately.
2. **Stable identity, WeakRef and shared defaults.** Own focused heap identity/weak-reference modules, `realm.rs`, `value.rs`, stored-value reads, `native_closure.rs` and a registration module. Introduce explicit stored versus real reads, cached weak wrappers, source-visible registration metadata and shared roots. Test same/different aliases, clone/read/expiry, weak env and actual source refcounts/GC order; no delegate storage semantic rewrite.
3. **Nested evaluator and native-call adapter.** A private `invoke_native_boundary(callable, argument_range, result_destination, policy)` returns a typed outcome while sharing VM storage/debt. Script entry creates a fresh Execute root/trap boundary; native entry installs source CallInfo and applies full arity/masks/env/return behavior. `sq_call` adapter remains separate because its stack/result/can_suspend behavior differs. Test nested inner/outer catches, ignored errors, valid tails, varargs, negative debt, error roots, cleanup and old calls under both profiles.
4. **Table hook consumers.** `lookup_meta(receiver, kind)` returns an internally retained immediate hook, without invoking or recursively searching. `invoke_meta` yields `Unavailable`, `Returned(value)` or `Raised(typed_error)`; uncatchable policy/invalid/undefined failures use the outer Result error and cannot enter fallback. Result destination owns values only for their source lifetime. Operation-specific adapters in roots/tables/updates/operations/frames apply the table above. No one catch/ignore policy for all hooks. Bring all inherited 18 bodies/108 required pairs and additional hook bodies from RED to exact GREEN.
5. **Default native bodies.** Separate table, closure, weakref, array and string/number body modules sharing registration/type checks and nested invocation. Implement all 48 current-family registrations and their diagnostics, identities and actual operations; source heapsort is its own coherent helper. Preserve own/raw/real-read distinctions and the exact default lookup order. Add source-valid empty/arity/type/alias/partial-failure controls before each body family is accepted.
6. **Evidence/bindings only after semantic freeze.** Mandatory source hashes/copies/modes for all new helpers and observer headers, meaningful missing/tamper refusals, all existing source/assets/statuses, current exact compiler-selected graphs/raw depfiles, full both-profile native recipes and the unmodified normal producer. No cap/parser/schema/driver/status changes. Current component contract is 1,024,824 bytes (23,752 below 1 MiB); report an actual integration size constraint before metadata edits rather than reducing functionality.

The ordering is intentionally prerequisite-first. Default identities may be constructed before their bodies are enabled, but no partially admitted registration may silently appear callable and then fake success. Public error signatures stay compatible; any additive Value variant/error category must be exhaustively reviewed at native observer/API boundaries. Compiler opcode generation for the already admitted syntax is not rewritten to avoid runtime work.
