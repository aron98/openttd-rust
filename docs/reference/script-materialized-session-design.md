# Materialized Squirrel session: implementation design

Design only, based on frozen `3072e1f058d71507ee3e811be173789d3aadc0ee` and OpenTTD15.3 `14ec60f248547d4d062a1160f0fc26d742319888`. No runtime, native exposure, metadata, admission or nested Execute changes are authorized by this document. This refines the approved [root roadmap](script-roots-design.md), preserves its scoped/weak collector boundary, and uses the actual tests/receipts in the accompanying report. All seven Stage04 gates remain OPEN.

## Source ledger and objects that must exist

The complete [registration ledger](script-session-registration-ledger.md) gives all70 entry names, C++ function symbols, signed arity, exact source typemask, compiled i64 masks and source lines:66 default entries across ten tables plus four bare-root entries,44 distinct function symbols. Aliases share code identity but **never closure identity**. Each closure has real name, function, masks, empty outers and Null environment. Source registration succeeds by storing real objects; precise unsupported invocation remains until its body is implemented. Empty tables or generic function placeholders cannot satisfy this design.

Source anchors below are relative to `src/3rdparty/squirrel/`. Shared construction is `squirrel/sqstate.cpp:74–154`; base registration is `sqbaselib.cpp:241–292`; native closure layout/clone/finalize is `sqclosure.h:99–139`; type-mask compilation is `sqstate.cpp:37–72`. Build configuration is i64/f32/GC, EXPORT_DEFAULT_SQUIRREL_FUNCTIONS absent. Conditional base functions are not silently registered. Game host libraries are a later explicit configuration, not extra bare globals.

Construction ownership is also source-ordered: `CreateDefaultDelegate` holds its new table and each new closure as raw zero-reference pointers until the actual SQObjectPtr conversions/slot/shared-field assignments retain them. Use the existing unpublished-allocation principle, not public `Realm::table`/NativeClosure constructors that add HostRoot owners. Private builders retain/move only the source temporaries and published edges; the InitGuard is storage custody, not a graph owner or GC root. The metamethod map/registry/const owners publish immediately at their assignments; a default table publishes to its shared field only after its entries finish. During base registration, actual VM stack slots own the pushed root/key/closure until source Pop/CreateSlot releases them.

Source accounting is13 shared tables + root + primary VM +70closures =85 collectables. The native observer independently saw85 nodes but did **not** type-classify unknown nodes. The executed lower-bound RED uses thirteen same-process registered table labels and a separately observed root, whose distinctness follows actual SQVM::Init allocation while shared tables remain live; it is not fourteen registrations or cross-process pointer matching.

Two existing representations need explicit changes before enabling materialized execution: `realm/constants.rs` BTreeMap/Rc enums must become real table-backed `_consts`/enum values in materialized realms, with compiler publication/lookup order (`sqcompiler.cpp:284,1128–1153`) and partial compile effects preserved; a duplicate decorative const table is forbidden. `NativeFunction` currently has four public variants and `NativeClosure::function() -> NativeFunction`; real registration needs forty further default function identities. Recommend an added `NativeFunction::Default(DefaultFunction)` with40 source-symbol variants, keeping four existing variants/signature and aliases. This changes downstream exhaustive matching and needs explicit interface approval; do not substitute a builtin or panic-producing placeholder. Class/generator/thread defaults still receive real metadata even while execution remains refused. Existing `type_checks() -> &'static [i64]` also needs an explicit bridge: the finite registration descriptor supplies its exact static mask slice, while materialized closure storage owns the source-shaped numeric mask vector and clone copies it. All currently proposed registrations/clones have immutable literal masks. Arbitrary host mutation of masks is not admitted by this bridge and requires a separately approved API; no leak-to-static or fabricated descriptor.

Compiler materialization is not just replacing the final constants map. `sqfuncstate.cpp:99–109,497–509` allocates actual `_literals` and `_strings` tables for every function state; CreateString retains interned names as keys, and CreateTable retains enum tables as **aggregate table keys** in `_strings` before `EnumStatement` publishes into `_consts`. Their logical references are compiler-local, not automatic GC roots. The materialized compiler therefore needs actual transient table lifetimes and private aggregate-key storage/hash/key-edge marking in addition to the authoritative const table. Current scalar-only table keys/edge traversal and BTreeMap/Rc enums are insufficient. Do not replace these tables by a keeper Vec or claim constructor-only coverage establishes compile-time graph fidelity. This joins the stable-identity prerequisite; legacy compiler behavior and external aggregate-key admission remain unchanged until their own source-backed port.

## Concrete ownership layout

| Proposed private type | Fields / ownership | Invariant |
|---|---|---|
| `ContextId` | arena index + u64 generation, scoped by checked session generation | identifies a real materialized VM; never a table surrogate, Runner address or fabricated identity |
| `ContextLife` | logical native refcount, retirement state, Weak heap/state link | Rust storage custody/Rc upgrades are not native owners; primary `_root_vm` contributes exactly one logical reference |
| `ContextRecord` | ContextId, lifecycle, numeric membership, actual scalar counters, chain links, storage kind | registry owns no Value mirrors; empty/null positions are represented explicitly |
| `PrimaryContext` | stable actual VM storage, direct authoritative Runner payloads after Init, physical stack/call/vararg/trap storage | session-owned; collector cannot finalize this VM while shared `_root_vm` is live |
| `PrivateContext` | stable actual VM storage; privately owned root/error/handlers/temp and physical buffers | registry can finalize it after releasing metadata borrows; no public unretained `&Value` can escape |
| `SharedRoots` | single internal ownership edges for registry,consts,meta,ten defaults,primary context; interned string owners | internal edges do not retain Realm and create no Rc cycle; root enqueue order differs from allocation order |
| `RootMembership` | collectable target enum Object(ObjectId)/Context(ContextId), or NonCollectable/Null; slot kind/index | scalar only, no AddRef/HostRoot promotion; generation/realm checked on publication and consumption |
| `NativeCollector` | Weak state + session generation | may transiently upgrade memory custody, never add a graph owner or keep a session logically open |

A context progresses Allocated→Initializing→Live→FinalizedReferenceLive→Retired. Finalize and reference retirement are separate: clear only native-defined fields while keeping remaining storage safe; generation invalidation occurs only at actual retirement. Reuse increments generation, never wraps; exhausted slots remain unavailable and checked allocation may fail. Reference-only locals, physical stack ownership, explicit host RefTable retention and primary shared retention are distinct. Mark state and lifecycle are not inferred from Object=None or chain membership; the current observer explicitly reports reference-live/off-chain only.

Primary storage is allocated at the real SQVM allocation point with Null pending payloads, not after building a Runner/root. Factory Init later moves its sole root/error/temp owners into bound Runner RootSlots without duplication; the stable context allocation and ContextId stay unchanged. Handler/debug roots and physical buffers remain actual context storage. The existing public const constructor stays unbound and unchanged. Private contexts use a collector-owned payload form capable of representing Null root after Finalize, unlike current `RootEnvironment`'s always-Table type. A borrowed primary is protected by the actual shared root; private unrooted contexts expose only numeric/reference tokens, never an unrestricted borrowed Runner.

Chain bookkeeping must preserve the native intrusive previous/next/head operations and marking reconstruction (`sqstate.cpp:268–347`), including the measured detached local-friend head-null result. Merely removing an absent ID from the current Vec is not equivalent. At retirement, invalidate weak target values and logical generation, remove/release in source order, then retire actual payload storage. The bounded observed friend-close path is allowed by its existing source proof; no second collection/execution/reset of that finalized unrooted friend is newly admitted.

## Public boundary and precise proposed signatures

The following are proposed **new** signatures, not changes to existing Runner/Program/Vm/Value methods. Native reference wrappers are necessary because current Program::Clone and Execution::Returned(Value) expose HostRoot ownership, whereas the original observer main/result locals are reference-only SQObjectPtr values (`program.rs:4–7`, `vm.rs:24–30`, native `active_owners.hpp:74,104`). `NativeProgram` owns an internal reference-only compiled closure; `NativeExecution` is Suspended or Returned(NativeValue), whose private reference keeps storage alive without making a GC root. Neither wrapper implements implicit Clone/Deref to its legacy owner. Borrow-only scalar/string/type/identity inspection creates no owners; explicit export calls the existing public HostRoot clone. True native host retention uses the separate RefTable token, not export. NativeProgram metadata inspection exposes only borrowed/scalar prototype fields; native start uses its private reference without a public Program clone. Legacy public results remain HostRoot values unchanged.

The factory is additive. Refine its previously illustrative VmError return to a separate `NativeContextError` so constructor/closed/foreign/capability failures are not script exceptions. Proposed variants: Allocation, InvalidInitialSlots, ClosedContext, StaleContext, ForeignContext, CollectionReentry, IncompleteNativeGraph. Existing VmError/CompileError/native error strings/signatures stay intact; no fabricated error Value. Runtime VmError still describes actual execution outcomes.

```rust
NativeSession::open(initial_slots: usize) -> Result<NativeSession, NativeContextError>
NativeSession::realm(&self) -> &Realm
NativeSession::primary(&mut self) -> NativeRunner<'_>
NativeSession::collector(&self) -> NativeCollector
NativeSession::close(self)                         // consumes the session
NativeCollector::collect(&self) -> Result<usize, NativeContextError>
NativeRunner::compile(&mut self, source: &str) -> Result<NativeProgram, CompileError>
NativeRunner::compile_bytes_named(&mut self, bytes: &[u8], name: &CStr) -> Result<NativeProgram, CompileError>
NativeRunner::start<'a>(&'a mut self, program: &NativeProgram) -> Result<NativeVm<'a>, VmError>
NativeVm::resume(&mut self, credit: u32) -> Result<NativeExecution, VmError>
NativeValue::view(&self) -> NativeValueView<'_>
NativeValue::export_host_value(&self) -> Value
NativeRunner::native_error(&self) -> Option<&ByteString>
NativeRunner::native_error_value(&self) -> &Value
NativeRunner::reset_native_error(&mut self)
NativeRunner::replace_root(&mut self, root: RootEnvironment) -> Result<(), VmError>
NativeRunner::set_print_sink(&mut self, sink: Option<Box<dyn PrintSink>>)
```

NativeRunner is a non-clonable scoped forwarding capability, with no DerefMut or unrestricted mutable Runner. Its creation proves live generation/root protection until scope ends; forwarded compile/error APIs need no new context error wrapper. Existing `pub const Runner::new`, const error accessors and public Value/Handle Clone remain exactly their bounded host APIs. No lazy registration at Print, adoption of a pre-existing arbitrary Realm, or enrollment of every RootEnvironment. `open` creates a fresh realm and returns only after complete initialization; incomplete construction cannot export collector/runner/realm.

On a live materialized Realm, existing `collect_cycles(&self)` dispatches to the native root enumerator too, so an ordinary PrintSink cannot accidentally select the legacy algorithm. Checked NativeCollector validates live generation before any mutation. While constructing/closing, collection has no valid native capability; after close, cloned Realm host cleanup is safe but is not native collection credit. The primary execution borrow prevents consuming/closing the session; weak capabilities surviving close fail ClosedContext. A registry phase check is not an extra root.

Public retained-friend access is an additive, explicitly named API: `NativeSession::retain_friend(&mut self, initial_slots: usize) -> Result<RetainedNativeFriend, NativeContextError>`; `NativeSession::friend<'a>(&'a mut self, token: &'a RetainedNativeFriend) -> Result<NativeRunner<'a>, NativeContextError>`. Creation performs actual friend allocation/Init/Push, then explicit RefTable AddRef, then Pop; token drop releases that actual host retention. The view borrows both session **and token for the same lifetime**, so token drop cannot remove its protection while a borrowed error survives. It validates token realm/generation; collection cannot finalize its host-rooted payload. Tokens contain no freely borrowable Runner and no implicit Clone (an explicit `retain` repeats RefTable AddRef). Close invalidates remaining tokens; their later Drop must be memory-safe/inert, not invoke native release on freed state. Source-comparable recipes release tokens before close and claim no native post-close-token behavior. Internal bare-local contexts use a different non-root reference token and private storage; ordinary legacy Runner::friend is not silently reclassified. This API waits for the real RefTable/identity prerequisite below. A retained-friend view moves the stable private payload box into a scoped storage lease and reattaches it to its reserved arena slot on Drop, without changing ContextId/address/logical owners. Metadata remains visible; no RefMut of the context arena/payload spans execution or Print. The token guarantees the detached-for-borrow context is marked. Reattachment is allocation-free and unwinding-safe. Bare-local contexts are never detached for a public borrow.

## RootSlot publication and callback safety

Persistent membership order is error,handler,debug,root,temp; physical slots ascend across **allocated stack size**, then physical varargs and active call closures (`sqobject.cpp:491–501`). Shared enqueue order is primary; RefTable physical nodes; registry,consts,meta; table,array,string,number,generator,thread,closure,class,instance,weakref. Mark at enqueue/deduplicate, pop LIFO and prepend into the new chain. Numeric membership is the collector's authority; querying/cloning Runner Values during marking would add owners or violate borrows.

| Write form | Required transaction |
|---|---|
| Copy SQObjectPtr assignment | pre-reserve any metadata; retain incoming actual owner; publish payload/type + matching scalar membership; release displaced owner after registry/heap borrows end (`sqobject.h:326–355`) |
| Null / move-to-null | preflight binding; publish Null payload and Null membership, then release displaced owner (`sqobject.h:300–309`) |
| Primitive integer/float assignment | preserve the reached source overload's release-before-raw-init order where used; retain the old numeric membership through that source release phase, then publish the scalar/null metadata; no newly admitted callbacks during this transient write; audit each writer rather than imposing one blanket setter |
| Native move assignment | source is swap, not discard-old: publish both slot payloads/memberships as a pair, with no reference-count events until actual displaced owner later drops |
| Vector growth/clear or frame relocation | reserve real payload and scalar-slot storage before publication; move owners and IDs once; retain null slots and allocated length; source destruction/clear order, not arbitrary Vec capacity |

No mutable registry or heap borrow survives a release/finalizer/PrintSink. Reserve membership capacity before fallible growth; persistent fields have fixed reserved slots from construction. The mark pass briefly borrows scalar membership, copies ordered IDs into the mark work storage, drops that borrow, then walks/finalizes; it does not add Value owners. Finalization actions take payload pieces out under short private-context borrows, release them afterward. Primary persistent storage stays directly borrowable: `_root_vm` makes it marked, so native GC cannot finalize its borrowed last error. Root replacement/reset need exclusive Runner access and cannot overlap that borrow. HostRoot Clone remains a real host extension, not renamed RefTable.refs; source-comparable producers must use explicit source-corresponding retention.

Active Print path: initialize capability before installing sink; bind actual physical slot/frame writes from start onward; release transient borrows before invoking host print; the sink uses Weak NativeCollector and never borrows active Runner mutably. It snapshots current authoritative membership and collects without suspending/restarting execution or adding credits. Native allocation/mark work must finish without callbacks during enumeration. Ordinary unmarked private reference operands can be finalized; active primary cannot. Internal thread execution and nested Execute attachment remain separate prerequisites, not enabled by this factory design.

## Initialization, failure and close transitions

Context scalars mirror native widths: SQInteger counters/op debt/error threshold signed64; SQBool/raw reference counts unsigned64; CallInfo etraps/prevbase/prevtop/target/ncalls signed32; vararg base/size unsigned16. Constructor initializes suspended=false,target=-1,root=false,traps0,foreignptr null,nnativecalls0,handlers/error Null,can_suspend=false,overflow=false,debt0,thresholdINT64_MIN,calls pointer null/size/capacity0,top/base0,ci null. Preserve source CallInfo default/value initialization; inactive records are not marker roots or exposed by the current observer, so their complete scalar contents have no experimental credit. Init makes stack size initial_slots and four call records, then root/registration. Source sqvector size versus capacity and NDEBUG Push growth (`squtils.h:53–70,103–116`, `sqvm.cpp:1543–1555`) must be represented; zero initial capacity is not admitted. Checked size conversions/overflow fail before allocation; initial native-backed targets remain256 and game1024, with broader safe-size branches requiring tests, not arbitrary clamping.

Factory uses an unpublished InitGuard and records exactly completed milestones plus every zero-reference unpublished allocation. Guard bookkeeping reserves its scalar ID capacity before publication and owns no graph references. A failed default-table/closure builder therefore cannot leave the existing Unpublished-style orphan behind: rollback finalizes/drains the recorded unpublished prefix directly, without calling normal GC with a null primary root. No external observer/capability exists before Live, so recoverable Rust initialization failure is an infrastructure result, not a native script error or a new partial usable session. Native observer allocation aborts on failure; OpenTTD ScriptAllocator instead throws Script_FatalError for quota/OS failure (`script/squirrel.cpp:35–173`). No original OOM/crash experiment or exact failure parity is claimed. Native Init currently returns true on its normal body; its false branch is not a tested rollback oracle.

| Failure milestone | Deterministic Rust rollback, outside borrows |
|---|---|
| Before any collectable | drop allocated string/vector/RefTable infrastructure in completed reverse-construction order |
| Shared prefix only | clear owners of completed defaults in reverse construction; finalize/drop existing registry,const/meta only if present; clear constructor/system/metamethod string owners and interner last; drain actual queued releases |
| VM allocated, no Init root | clear any initialized scalar membership/buffers; release actual primary shared reference if published; retire context only when refcount reaches zero; then shared-prefix rollback |
| Root/base partly registered | finalize existing primary fields in source order, null actual initialized stack slots in reverse, release completed base entries through real root teardown; no publishing half-bound Runner; then close completed shared prefix |
| Fully initialized before return | use the complete normal close sequence; invalidate capability generation before any reentrant host path can collect closing state |

Every checked allocation/reservation gets an allocation-site identifier for test-only failure injection, without native hooks. Test one failure at each completed milestone, zero leaked native owners, exact surviving independent-realm state and a later successful factory. Public existing infallible Realm.string/BTreeMap allocation is not thereby made fallible: this design retains their global allocator-abort semantics rather than promising an unimplemented fallible interner. Checked Vec/table/context reservations return Allocation and use the guard; infallible Box/Rc/string-map allocations may abort exactly as the bare observer allocator does. Game ScriptAllocator quota/fatal-error handling remains required separately. `Result` covers checked allocation/context errors only; do not promise recovery from process OOM. No arbitrary source resource limit is introduced.

Normal close source sequence (`sqapi.cpp:128–133`, `sqstate.cpp:156–200`, `sqvm.cpp:129–145`): mark Closing; first primary Finalize (root,error,handler,debug,temp,call storage, complete stack reverse); clear constructor index; Finalize registry,const,meta then release those fields; clear system strings reverse; primary Finalize again; drop shared primary owner (actual destructor Finalize/unlink at retirement); release defaults in declaration order; RefTable.Finalize physical ascending; sweep/drain remaining collectables; destroy type/system/meta vectors and string table last. Native varargs are **not** cleared by Finalize itself; destructor member release remains separate. Null/previously-cleared fields make repeated Finalize valid. Rust payload teardown must be explicit, not rely on arbitrary struct field order. Source-comparable close releases all explicit host tokens beforehand. Extra public Rust HostRoot aliases are a memory-safe host extension: finalize their contents without forcibly freeing live Rust handles, and give no native post-close lifetime credit. All externally borrowed primary/friend views are gone before close; surviving public host Values remain safe with source-cleared contents but cannot revive native context capability.

## RefTable identity boundary: precise physical algorithm, storage prerequisite unresolved

The slot algorithm is fully source-derived (`sqstate.cpp:367–515`): four initial slots/buckets; ascending free chain; add takes first free slot, stores one owning object, prepends to hash bucket and increments used; repeated AddRef only increments node refs. Release decrements refs; final removal first retains a temporary object, unlinks bucket node, prepends freed slot, decrements used, nulls slot owner, then drops temporary at function exit. Resize occurs only when full, doubles capacity, scans old physical nodes ascending, Add-reinserts and copies refs, nulls old owners, then frees old storage. Mark and Finalize scan physical slots ascending, including strings occupying slots even though noncollectable. No shrink is implemented. Fields/counters are u64, logical next/bucket indexes replace source pointers without changing ordering.

Hash/equality cannot silently use ObjectId hashing: source HashObj uses string `_hash`, float→i64 for defined-range floats, bool/integer raw bits, otherwise actual object pointer arithmetic-shift3; bucket mask is capacity−1, equality requires both raw value and exact type (`sqtable.h:12–21`, `sqstate.cpp:466–487`). sq_addref accepts only refcounted types. The existing arena moves payloads, and Rc<Life> weak control blocks can outlive retirement, so neither arena address nor generation nor Rc control-block reuse is a proven native raw identity substitute.

Separate prerequisite proposal: stable **actual payload** allocation for each native object/context, with safe own-process address inspection and no integer-to-pointer dereference. Its token lifetime ends at actual retirement even if weak observation control blocks survive; same alias has same address, distinct live objects differ, reuse after retirement is permitted. Do not allocate empty identity-only boxes or fake constants. This requires a focused payload-storage design and tests for address format/alias/lifetime/reuse and hash/read effects before choosing layout. Full native pointer numeric equality across processes is not required; raw outputs stay unnormalized. Until approved, RefTable hash-backed host retention/public native friends and default weakref execution are not implementable/admitted shortcuts. This separation does not waive them or permit a partially initialized public NativeSession.

## First bounded implementation candidate

A private constructor/idle-only `MaterializedIdle` atom is independently startable: build the complete initial13sharedtables/66closures, actual primary/root/base4closures and empty four-slot RefTable, then prove idle root/owner/close order. It does not hand out NativeRunner. Requests to acquire compiler/execution/active-Print or nonempty-RefTable capability return `IncompleteNativeGraph` before mutation; they do not invent CompileError/native strings. This preserves an explicit registry-only boundary without claiming that compiler transient tables or full frame writers are already implemented. The public NativeSession/NativeRunner signatures above are the eventual complete interface, not a promise to expose a partially executable factory in the first atom. Final public exposure and ordinary CLI adoption wait for the required compiler, identity/RefTable and active-slot pieces. The narrower atom leaves the full materialized-session goal intact.
