# Contract-only content

The `contract-speed.hex`/`.grf` and `contract-probe/*.nut` files are self-authored
by this project's contributors for the native Stage 1 compatibility corpus and
licensed GPL-2.0-only. The license text is in [LICENSE](LICENSE). They contain no
third-party sprites or add-on code. `metadata.json` pins each retained asset.

See [the fixture recipe and boundaries](../contracts/README.md) for exact native
commands, observable effects, save/load state and protocol checks. This content
is a small test fixture, not a published add-on or a claim of Rust mod support.
